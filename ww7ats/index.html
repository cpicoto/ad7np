Install the Windows release

  1. Download and run the WW7ATS per-user setup program; administrator rights are not required.
  2. If Microsoft Defender SmartScreen appears, select More info, verify the filename shown here, then choose Run anyway.
  3. Start WW7ATS from the Start menu and choose the camera and microphone in Settings.
  4. Enter your callsign, WW7ATS server details, and private stream key before transmitting.
Unsigned release: Windows may display a Microsoft Defender SmartScreen prompt. Only continue if the file came from this page. SHA-256: d799b2ee1763128a1a5a4d0dc8d27470ba4048185e0942dd69218448f0e9c71a. Never share your stream key.

Requirements

  • Windows 10 or 11, x64
  • Camera and microphone
  • Internet connection
  • Licensed amateur radio operator for transmission
